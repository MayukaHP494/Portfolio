Added `falcone.html`, `falcone.css` and 19 optimised photographs in `images/falcone/`, extracted from the FalconE portfolio PDF. The new project card opens the contribution page in a new tab. Photographs on the contribution page link to their full image files.

Removed the CFD Analysis Projects and 3D-Modeling Projects cards and their unused document-link configuration. The other three projects retain their existing document links.

## Publish to your existing GitHub Pages site

1. Extract this ZIP.
2. Open your `MayukaHP494/Portfolio` repository on GitHub and select the branch used by GitHub Pages.
3. Choose **Add file → Upload files** and upload the contents of `Portfolio-main` into the repository root. Include the new `images` folder. Do not upload the enclosing `Portfolio-main` folder itself.
4. Commit the changes. If GitHub Pages publishes from this branch and folder, its existing deployment will update the site.
5. Open the website's Projects section and select **View FalconE Portfolio**. The new page is `falcone.html` alongside `index.html`.
